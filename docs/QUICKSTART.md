# Quick Start

## 5 分钟跑起来

### 1. 克隆

```bash
git clone https://gitee.com/qingyuanfanshenrengongzhineng/qyfanshen.git
cd qyfanshen.com
```

### 2. 环境准备

- PHP ≥ 8.0

### 3. 启动

```bash
php -S 127.0.0.1:8080 -t .
# → http://localhost:8080
```

### 4. 下一步

- 阅读 [`ARCHITECTURE.md`](ARCHITECTURE.md) 了解系统设计
- 阅读 [`DEPLOYMENT.md`](DEPLOYMENT.md) 部署到生产环境
- 阅读 [`API.md`](API.md) 查看接口文档
